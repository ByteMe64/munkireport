# CLAUDE.md

Deployment wrapper (not the app itself) for [munkireport-php](https://github.com/munkireport/munkireport-php). PHP source is downloaded in `Dockerfile` at build time. No tests or build scripts. Setup steps are in each `env*` template's header comments.

## Gotchas

- **entrypoint.sh generates the app .env**: MunkiReport-php reads `/var/munkireport/.env`, not OS env vars. `entrypoint.sh` writes Docker env vars into that file on every start. New config vars must be added to both `entrypoint.sh` and compose `environment:`.
- **No bind mounts by design**: All state in named volumes. Traefik uses file provider (not Docker provider) — routing generated by `traefik-init` into a volume. Don't add bind mounts or Docker socket.
- **Passphrase name translation**: `.env` `CLIENT_PASSPHRASE` → compose maps as `PASSPHRASE` → entrypoint writes `CLIENT_PASSPHRASES` (plural). Mismatch = silent client registration failure.
- **Admin hash quoting**: Wrap bcrypt hash in single quotes in `.env` — `ADMIN_PASSWORD_HASH='$2y$10$...'` — to prevent `$` interpolation.
- **Portainer compose is standalone**: `docker-compose.portainer-demo.yml` duplicates the full stack (not an overlay). Keep shared services in sync with `docker-compose.yml`.
